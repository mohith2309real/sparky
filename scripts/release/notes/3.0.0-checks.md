# Sparky 3.0.0 verification — 2026-10-12

- 675 checks across 20 native suites; 13 browser-language checks.
- macOS Apple silicon: frozen app, IDE, streamed mock AI reply, ad-hoc code
  signature, DMG, code-pack update, failed-start rollback and full-app replacement.
- Python 3.10: all application modules compile; eight headless suites pass.
- Linux ARM64 (Debian 12) and x86_64 (Ubuntu 22.04): app, IDE, installer,
  MIME/default-app registration, streamed mock AI reply, code-pack and full updates.
- Windows (Wine on Debian 13): app, IDE, streamed mock AI reply, code-pack update,
  portable launch and local data. Installer payload matches the tested source.
- All six release artifacts match the Ed25519-signed SHA-256 list.
- Website: responsive layouts, signed download manifest, shared programs do not
  auto-run, working Spiral/list/shape examples and local links across seven pages.

The first Windows installer-registration attempt lacked Wine's 32-bit support.
The NSIS launcher is 32-bit although Sparky itself is 64-bit. The test harness now
installs both Wine architectures. The dedicated retest reached a Rosetta failure
(`invalid gdt selector index 5`, installer status `c0000018`): this Apple-silicon
Docker environment cannot execute that 32-bit launcher. Windows registration
remains unverified at runtime; the 64-bit app and portable ZIP passed under Wine.

Runtime 2 is required because bundled Windows/Linux dependencies changed.
No runtime-1 code pack is published for this release.

Physical Arduino uploads and a native Windows PC have not been tested. Intel Mac
support remains deferred. macOS signing is ad-hoc, without notarization.

Local evidence: `build/final-checks/`, `build/verify-final-complete.log` and
`build/final-checks/wine-installer-check.log` (build outputs are not committed).
