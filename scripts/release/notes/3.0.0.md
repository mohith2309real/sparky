# Sparky 3.0 — Little ideas. Real code.

Sparky 3 brings thirty offline lessons, checked challenges, project templates,
sprites and events, music, a real debugger, Python learning and Arduino tools.
The optional AI tutor has per-project chats and previews before inserting code.
Classroom controls, assignments, local hand-ins and accessibility settings help
more people use the same native app.

The final release adds signed news and featured projects on Home, panels that
load when opened, clearer console messages, activity badges, gentle motion and
friendly empty screens. Featured projects open as copies and never run themselves.

There are refreshed installers and file associations for Mac, Windows and Linux,
plus a portable Windows ZIP that keeps its settings and projects beside the app.
The new website shares the app's design tokens and includes a reference, teacher
guide, featured projects, verified download information and browser share links.

Intel Mac support remains planned for later. Physical Arduino uploads and the
Windows installer on a real Windows computer have not been verified. Mac builds
use ad-hoc signing and are not notarized. Hindi and Telugu cover core controls;
lessons and the language itself remain English.
