## 2026-11-03 - AST Node Dispatch in Tree-Walking Interpreters
**Learning:** In CPython, a deep recursive tree-walking interpreter (like Sparky's generator-based one) evaluates AST nodes thousands of times per second. During node evaluation and statement dispatch, replacing dynamic `getattr` logic and sequential `isinstance` checks with exact `type(node)` equality matching provides a measurable, global performance improvement. This applies strictly when AST nodes are not subclassed, allowing `type(node) is ExpectedType` to be safely used over `isinstance(node, ExpectedType)`.
**Action:** When working on language interpreters built in Python, if no polymorphism is expected in AST nodes, favor `type(node)` dispatch mechanisms (or method caches) over `isinstance` chains to squeeze out extra speed in hot evaluation paths.
